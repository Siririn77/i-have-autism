Нет, для денег `float` — плохая идея.

Причина: числа с плавающей точкой (`float`/`double`) хранят значения в двоичном формате и не могут точно представить многие десятичные дроби. Например:

```python
0.1 + 0.2 == 0.30000000000000004
```

При накоплении сумм, расчёте налогов, скидок, процентов и сверке балансов это приводит к ошибкам округления, «копейкам» и проблемам при сравнении.

Как лучше:

- **Decimal / точная десятичная арифметика**:
  - Python — `decimal.Decimal`
  - Java — `BigDecimal`
  - C# — `decimal`
  - SQL — `NUMERIC`/`DECIMAL`
- Или хранить деньги **в целых минорных единицах**: копейки, центы. Тогда 10.50 ₽ хранится как `1050`.
- Для валюты обязательно фиксируйте правила округления.

`float` допустим только для приблизительных аналитических расчётов, где точность до копейки не важна. Для хранения и учёта денег — нет.
