```
git diff -- <путь к конфигу>; <команда сборки> 2>&1 | tail -40
```

Причину падения назвать нельзя: в вопросе нет ни diff правки, ни текста ошибки, а без них любая версия причины будет выдумкой, а не ответом. Пришлите вывод этих двух команд — и я укажу конкретную строку конфига, которая ломает сборку, и правило, которое она нарушает.
