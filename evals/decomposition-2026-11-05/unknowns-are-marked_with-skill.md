Приложи файл с продажами (CSV/XLSX) или вставь строки — без данных чисел не будет.

**Что нужно в файле (минимум)**
- дата заказа
- сумма

**Что нужно, если делаем разбивку**
- регион или менеджер
- статус: оплачен / возврат / отменён

**Какой квартал считать прошлым**
По умолчанию возьму последний завершённый календарный квартал. Если нужен скользящий (3 последних полных месяца) — скажи одним словом.

**Что я сделаю, когда файл будет**
1. Итог за квартал: сумма, число заказов, средний чек.
2. Сравнение с предыдущим кварталом.
3. Разбивка по названному разрезу.
4. Проверки: сумма отчёта = сумма по исходнику; строки с пустой датой или суммой — перечислю отдельно, молча не выкину.

**Состояние:** данных нет, путь к файлу не назван. Сейчас отсутствует файл — это единственное, что блокирует отчёт.

Одно действие: приложи файл.
