`hello.py`
```python
print("hello world")
```

План (3 строки):
1. Вход: нет. Действие: `print` строки `hello world`. Выход: одна строка в stdout. Проверка: вывод совпадает посимвольно.
2. Файл создаётся вручную: содержимое выше — это весь файл.
3. Запуск проверяет выход.

Создать файл и запустить:
```
python hello.py
```
Ожидаемый вывод:
```
hello world
```

Что теперь работает: скрипт печатает одну строку `hello world` и завершается с кодом 0.
