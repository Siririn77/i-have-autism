`hello.py`:

```python
print("hello world")
```

План (2 строки): вход — нет; действие — один вызов `print`; выход — одна строка в stdout; проверка — код возврата 0 и строка ровно `hello world`; отказ — строка другая или код не 0.

Запуск:

```
python3 hello.py
```

Ожидаемый stdout:

```
hello world
```

Проверка одной командой:

```
python3 hello.py | grep -qx 'hello world' && echo OK
```

Печатает `OK` при совпадении строки.

Что теперь работает: файл печатает строку без аргументов и без зависимостей.
