**1. Создай файл `hello.py` с одной строкой.**

```python
print("hello world")
```

**Граф (3 узла)**

| Что | Зачем | Якорь | Когда |
|---|---|---|---|
| `hello.py` с `print("hello world")` | единственный результат задачи | `python3 hello.py` → `hello world` | сейчас |
| Проверка stdout | строка совпадает посимвольно, без лишних пробелов и перевода каретки | вывод равен `hello world\n` | после записи файла |
| Проверка кода возврата | скрипт падает молча в другом окружении | `echo $?` → `0` | после запуска |

**План (одноразовый, 2 строки)**
- Вход: ничего. Действие: записать `print("hello world")` в `hello.py`. Выход: файл. Проверка: `python3 hello.py` печатает ровно `hello world`.
- Неизвестных нет `[?]`. Правок не было, журнал дрейфа пуст.

**Как проверить**

```bash
python3 hello.py
# hello world
echo $?
# 0
```

Работает: печать строки в stdout. Проверка выше — единственный тест, который может упасть (несовпадение символов или ненулевой код возврата).
