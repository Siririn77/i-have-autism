Без фрагмента файла нельзя гарантировать точную правку, но если смысл в том, чтобы суммировать **все** элементы списка, а не только первые два, то строку нужно заменить на:

```python
total = sum(items)
```

Остальные три таких же места исправляются аналогично:

```python
<переменная> = sum(<список>)
```

Если `items` — не список чисел или там нужна другая логика, пришли фрагмент файла — покажу точные замены для всех четырёх мест.
