Без файла не могу гарантированно поправить все четыре места, но сама строка исправляется так:

Если `total` — это сумма **всех** элементов:
```python
total = sum(items)
```

Если нужна сумма **только первых двух** элементов, но список может быть короче:
```python
total = sum(items[:2])
```

Если же по логике в списке обязано быть минимум два элемента, лучше явно проверять:
```python
if len(items) < 2:
    raise ValueError("items должен содержать минимум два элемента")
total = items[0] + items[1]
```

Остальные три места замени аналогично. Если хочешь, пришли фрагмент файла — я укажу точные строки и сделаю правку для всех четырёх мест.
