Точную правку без файла дать нельзя: неясно, нужно ли суммировать **все** элементы `items` или только первые два.

Если цель — сумма всех элементов:

```python
total = sum(items)
```

Если действительно нужны только первые два:

```python
total = sum(items[:2])
```

Для остальных трёх мест аналогично замените жёсткие индексы на `sum(...)`, например:

```python
# было
x = items[2] + items[3]
# стало, если нужны элементы 2 и 3
x = sum(items[2:4])
```

Пришлите эти четыре строки или фрагмент файла — я дам точные правки для каждого места.
