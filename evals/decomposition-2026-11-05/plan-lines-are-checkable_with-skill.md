`plans/audio-preflight.md` — сохранить план по этому пути. Файловой системы у меня здесь нет, поэтому текст плана ниже; больше ничего в ответе нет.

**План без целевой площадки не проверяем.** Числа в шагах 6–8 (LUFS, dBTP) берутся из стандарта площадки; до выбора площадки эти шаги не имеют порога.

Один вопрос, до шага 1: **куда публикуется файл** — подкаст, YouTube, эфир/вещание? Стоимость каждого варианта:
- подкаст (Apple Podcasts, Podcast Standards): −16 LUFS стерео / −19 LUFS моно, true peak ≤ −1 dBTP;
- YouTube / Spotify: нормализация к −14 LUFS; мастер громче площадка уводит вниз, тише — поднимает с ограничителем;
- эфир EBU R128: −23 LUFS ±0.5, true peak ≤ −1 dBTP; мастер под −14 не проходит приёмку и уходит на пересборку;
- ATSC A/85: −24 LKFS ±2.

Пока ответа нет, в плане стоят символы `TARGET_LUFS` и `MAX_DBTP`.

## Раздел 1. Шаги проверки

**1. Зафиксировать критерии — 10 мин**
- Вход: раздел 0.
- Действие: заменить каждый `[?]` числом или словом.
- Выход: `acceptance.md` с заполненной таблицей.
- Проверка падает, если остался хоть один `[?]`.

**2. Заморозить артефакт — 2 мин**
- Вход: исходный файл.
- Действие: скопировать в `incoming/`, посчитать `sha256sum`.
- Выход: путь копии и хеш в журнале.
- Проверка падает, если хеш файла перед загрузкой не совпал с записанным.

**3. Контейнер и поток — 3 мин**
- Вход: файл из шага 2.
- Действие: `ffprobe -v error -show_format -show_streams -of json <файл>`.
- Выход: кодек, частота, разрядность, каналы, битрейт, длительность.
- Проверка падает, если частота ≠ раздел 0, каналы ≠ раздел 0, битрейт ниже минимума, длительность отличается от ожидаемой больше чем на 0.5 с.

**4. Целостность декодирования — по длительности файла, примерно 1/10 реального времени**
- Вход: файл из шага 2.
- Действие: `ffmpeg -v error -i <файл> -f null -`; для flac дополнительно `flac -t`, для mp3 — `mp3val`.
- Выход: пустой вывод ошибок.
- Проверка падает, если в stderr есть хоть одна строка: это обрыв или битый кадр.

**5. Уровни и срез — 2 мин**
- Вход: файл из шага 2.
- Действие: `ffmpeg -i <файл> -af astats=metadata=1:reset=0 -f null -`.
- Выход: Peak level dB, Flat factor.
- Проверка падает, если Peak level > −0.1 dBFS или Flat factor > 0 (подряд идущие сэмплы на одном уровне = срез волны).

**6. Громкость EBU R128 — 2 мин**
- Вход: файл из шага 2.
- Действие: `ffmpeg -i <файл> -af ebur128=peak=true -f null -`.
- Выход: integrated LUFS (I), LRA, true peak dBTP.
- Проверка падает, если |I − `TARGET_LUFS`| > 0.5 или true peak > `MAX_DBTP`.

**7. Коррекция громкости — только если шаг 6 упал, 10 мин**
- Вход: значения I, LRA, true peak из шага 6.
- Действие: two-pass `loudnorm` с этими значениями, вывод в **новый** файл.
- Выход: исправленный файл и повторный замер шага 6.
- Проверка падает, если после коррекции шаг 6 всё ещё падает, или длительность изменилась больше чем на 10 мс, или мастер перезаписан вместо нового файла.
