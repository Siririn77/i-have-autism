**Рекомендуемый текст ошибки для пустого поля email:**

> **«Введите адрес электронной почты»**

Короткие варианты:
- «Укажите email»
- «Поле «Email» обязательно для заполнения»
- «Введите email, чтобы продолжить регистрацию»

Лучше показывать сообщение под полем и связывать его с полем через `aria-describedby` для доступности.
