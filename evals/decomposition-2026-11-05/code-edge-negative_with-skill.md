`head([1, 2, 3], -1)` → `[1, 2]` — это не префикс, это «всё, кроме последнего».

**Граф (4 узла)**

| узел | что | почему важно | якорь | когда |
|---|---|---|---|---|
| отрицательный n | `xs[:n]` при n<0 режет с конца | тихо возвращает `len+n` элементов вместо ошибки | `xs[:n]` | n < 0 |
| имя ≠ контракт | `head` — первый элемент (Haskell `head`, `head -1`); сигнатура с n — это `take` | читатель ждёт один элемент, получает список | `def head(xs, n)` | при любом вызове |
| домен | срез требует `__getitem__` со slice | генератор, итератор, set → TypeError | `xs[:n]` | xs не Sequence |
| n ≥ len, n = 0 | возвращает копию целиком / пустой список | не ошибка, но «ровно n» не выполняется | `xs[:n]` | n ≥ len |

**Дефекты, по убыванию**

1. При n < 0 ошибки нет: функция молча возвращает элементы с начала, но не все — последние `|n|` отброшены. Вызывающий код ждёт префикс и получает хвост.
2. Имя `head` обещает один элемент, функция возвращает до n. Имя — `take`.
3. Работает только на последовательностях со срезом. Для остальных — `itertools.islice`.

**Исправление**

```python
def take(n, xs):
    if n < 0:
        raise ValueError(f"n must be >= 0, got {n}")
    return xs[:n]
```

**Проверка**

```python
take(2, [1, 2, 3])   # [1, 2]
take(0, [1, 2, 3])   # []
take(-1, [1, 2, 3])  # ValueError: n must be >= 0, got -1
take(5, [1, 2, 3])   # [1, 2, 3]
```
