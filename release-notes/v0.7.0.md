# Release 0.7.0: aggressive mode — absolute coverage on request

Normal mode lets a graph be incomplete: a region is cut, the plan writes "out of scope", and that is a
legitimate decision. Aggressive mode removes the one thing normal mode permits — **silence**.

It is opt-in. It runs only when the reader asks for it by name ("агрессивная графизация", "полное
покрытие темы", "aggressive graph"). Default behaviour is unchanged: this release changed nothing about
how a normal graph is built or checked.

## What "absolute coverage" means

Not "every fact in the world is in the graph" — that is an infinite set. It means **nothing disappears
without a written decision**:

- every node of the graph is either inside a unit of work, or **in the register** with a status, a
  reason and a place where it will be handled;
- every cell of a **coverage matrix** (axes × stages) either names node ids or says "не относится" — and
  a refusal costs a register row named `ось × этап`;
- the plan carries the register and the matrix, so a reader sees "Балканы — отдельный сезон, потому что
  не объясняются европейской логикой" instead of "Балканы — вне рамок".

Statuses are fixed: `в работе` · `отдельная часть` · `отдельный сезон` · `отдельный проект` ·
`не относится` · `нет данных`.

## New checks (eleven, on top of the ten)

1. every node is mapped or registered;
2. every register row has a non-empty reason;
3. every register row names a place;
4. the status is from the fixed list;
5. a row marked `в работе` really has a node;
6. the matrix exists;
7. no cell is empty;
8. a refusal has its `ось × этап` row;
9. every cell's node ids exist;
10. every node appears in at least one cell;
11. every axis has a row.

## Commands

```
python3 scripts/graph_new.py "тема" --kind history --aggressive --out graph.md
python3 scripts/check_graph.py graph.md --aggressive    # or "режим: агрессивный" in metadata
python3 scripts/graph_stats.py graph.md                 # covered / refused / holes
python3 scripts/graph_to_plan.py graph.md --out plan.md # register + matrix inside the plan
```

## Worked on the Second World War series

The graph was migrated to aggressive mode: 19 nodes, 5 axes, 5 seasons → a 25-cell matrix,
**17 cells covered, 8 explained by refusal, 0 holes**, and a register of 13 entries (Africa, the Balkans,
China 1937–1945, Latin America — each with a season or a project; plus the eight explicit refusals).

What the mode found that the eye had not:

- **Only one season was mapped.** Nodes 8–19 sat in the graph with no unit to carry them — the plan
  simply did not mention the Battle of Britain, Barbarossa, Lend-Lease, Stalingrad, Pearl Harbor, the
  bombing campaign, the Holocaust, occupation, radar, Yalta, Hiroshima, or the casualty dispute. That is
  exactly the "много где пропущено" the reader pointed at, and it was invisible in the plan because the
  plan never lied — it just stayed silent.
- **The cost of honesty.** Making every node reachable forced the mapping to the granularity of the plan:
  season 1's ten-part breakdown collapsed into one row, because the graph maps to seasons, not to parts.
  That is a real trade-off, recorded here instead of hidden: aggressive mode pushes the mapping to the
  level at which the work is actually scheduled.
