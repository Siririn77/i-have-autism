# Release 0.10.0: the cloud — composition as a small graph, and a higher ceiling

## The ceiling

The always-on section cap is raised from 4000 to 4500 characters. The rules file is 4015; the rendered
section is under 4400, so there is room to state a rule properly instead of compressing it into a telegram.

## The cloud

Ultra mode used to answer "what is inside this node" with a flat field `входит` and a list. A list says
what the parts are; it does not say how they relate. The field is gone. In its place, a **cloud**:

```
### Облако
- ядро: правовая дискриминация
| элемент | связь | с чем |
|---|---|---|
| правовая дискриминация | предшествует | изоляция |
| изоляция | предшествует | гетто |
| сопротивление и спасение | противопоставлен | логистика уничтожения |
```

It is a graph — elements and typed edges — but deliberately poorer than the master graph: no axes, no
anchors, no root questions, no budget in minutes. **The edge carries the meaning, and nothing else.**
Eight verbs, closed list:

`включает` · `предшествует` · `вызывает` · `усиливает` · `противопоставлен` · `цена` · `пример` ·
`доказательство`

A ninth verb would mean the cloud is being used for something it is not for. An edge whose label is a
sentence is prose with an arrow drawn next to it.

## What `cloud_lib.py` checks

1. a core exists — a cloud without a centre is a heap;
2. three to nine elements — two is a note, ten is a diagram nobody reads;
3. every edge uses a verb from the list;
4. no self-edge, no duplicate edge;
5. every element is reachable from the core — one cloud is one connected piece, and an island is where
   the thinking stopped.

## Worked on the Second World War

Nineteen clouds, all clean. Four were written by hand rather than generated, because a star of
`включает` from the core is a valid cloud but a boring one:

- `N2` — the reparations chain: payments → Ruhr occupation → passive resistance → printing money →
  currency collapse → the saver loses everything;
- `N9` — Barbarossa: deadlines **противопоставлен** distance, distance **вызывает** logistics, logistics
  **вызывает** mud and frost, and that is the stop at Moscow;
- `N13` — the bombing doctrine as a chain of means and costs, with the bombing command's own reports as
  `доказательство`;
- `N14` — the Holocaust as a sequence where each step was a law before it was a massacre, with
  `сопротивление и спасение` set against the machinery as `противопоставлен`.

The rest are honest stars: the node contains its parts. A star is not a failure; inventing verbs to make a
star look deep would be.

## Cost

Unchanged in kind, higher in degree: clouds add the vocabulary of relations on top of the prose. Still a
per-part tool, not a master-graph tool.
