# 0.14.0 — aggressive mode removed, ultra is the second mode

## What went

Aggressive mode is gone: the coverage matrix, the out-of-scope register, the eleven extra checks, the
`--aggressive` flags, the fixture, the plan sections it fed, and the eval arm that measured it. Its
files are not deleted from history — the release before this one still has them — but the toolkit no
longer knows the word.

It was removed because ultra asks the better question. Aggressive mode asked that nothing disappear
without a written decision; the matrix proved that a decision was recorded, not that the node was
understood. Ultra asks what is inside the node, and the fidelity bar added in 0.13.0 asks what would
prove it. One question, checkable, instead of two that overlap.

## What changed with it

- `graph_lib.py` no longer parses stages, the matrix, or the register.
- `check_graph.py` runs ten rules and nothing else.
- `graph_new.py` writes one template again.
- `graph_to_plan.py` writes a plan without matrix and register sections.
- The Second World War artefacts follow: `graph.md` lost the matrix and the register, the aggressive
  plan moved to `archive/plan-aggressive-2026-11-06.md`, and the plain plan was rebuilt from the graph.
  `check_graph.py` and `graph_expand.py --check` both pass on the cleaned graph, nineteen fidelity bars
  and all.

## Evals

Both suites now compare `none` / `graph` / `ultra`. The code suite measures bars per answer instead of
matrix and register, and `extract_code` no longer takes the last fenced block — once an answer carries
both a solution and the tests that prove it, the last block is the test suite.
